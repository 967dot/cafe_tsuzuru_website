# 喫茶 綴ル Webサイト

公共職業訓練の演習課題として制作した、架空の喫茶店Webサイトです。
提出後も、自主制作のポートフォリオとして改善を継続しています。

## 制作目的

HTML / CSS / JavaScript の基礎を用いて、複数ページ構成の静的Webサイトを設計・実装すること。
また、GitHubを用いたバージョン管理と公開運用に慣れることを目的としています。

## 使用技術

- HTML
- CSS
- JavaScript
- Git / GitHub

## 実装内容

- レスポンシブ対応
- ハンバーガーメニュー
- メニュー切り替え
- 営業カレンダー
- 複数ページ構成
- CTA導線設計

## 今後の改善予定

- セキュリティ観点でのフォーム設計見直し

## Security Notes

本サイトは静的サイトのため、サーバーサイド処理は含みません。
フォームはダミー実装であり、個人情報の送信処理は行っていません。
今後、フォーム送信機能を実装する場合は、入力値検証、CSRF対策、スパム対策、個人情報の取り扱いを考慮します。
